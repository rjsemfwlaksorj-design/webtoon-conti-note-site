개인정보처리방침

시행일: 2026년 10월 18일

1. 수집하는 정보

웹툰콘티노트(이하 "앱")는 개발자 서버를 운영하지 않으며, 사용자의 개인정보를 개발자에게 전송하거나 수집하지 않습니다. 사용자가 작성한 작품(시나리오, 콘티, 메모, 그림)은 사용자의 기기 안에만 저장됩니다.

2. 구글 드라이브 백업 (선택)

사용자가 직접 구글 계정을 연결한 경우에만, 앱은 구글 드라이브의 앱 전용 숨김 공간(Google Drive appDataFolder, 권한 범위 drive.appdata)에 작품 백업 파일을 저장하고 다시 불러옵니다.

  • 앱은 사용자의 다른 드라이브 파일을 보거나 읽거나 수정할 수 없습니다.
  • 백업 파일은 사용자 본인의 구글 드라이브에만 저장되며 개발자나 제3자에게 전달되지 않습니다.
  • 연결한 계정을 표시하기 위해 구글 계정의 이메일 주소를 기기 안에만 보관합니다.
  • 로그인 정보(토큰)는 사용자의 기기 안에만 보관하며, 앱 설정에서 "연결 해제"를 누르면 삭제됩니다.
  • 구글 계정 설정(myaccount.google.com/permissions)에서 언제든지 앱의 접근 권한을 철회할 수 있습니다.

앱이 구글 API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 준수합니다.

3. AI 변환 기능 (선택)

사용자가 AI 기능을 쓰기 위해 직접 입력한 API 키가 있는 경우에만, 사용자가 변환을 요청한 글이 사용자가 선택한 AI 서비스(예: Google, OpenAI, Anthropic)로 전송됩니다. API 키는 사용자의 기기 안에만 저장됩니다. 전송된 내용의 처리는 해당 서비스의 개인정보처리방침을 따릅니다.

4. 정보의 삭제

앱을 삭제하면 기기 안의 데이터가 삭제됩니다. 드라이브의 백업은 앱의 연결 해제 후 구글 드라이브 설정의 "앱 관리"에서 이 앱의 숨겨진 데이터를 삭제하여 지울 수 있습니다.
